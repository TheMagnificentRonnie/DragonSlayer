Stop-motion capture for the camera you already own.

DragonSlayer tethers your DSLR or mirrorless camera over USB, lets you shoot scene by scene with live view and onion skinning, and compiles the frames into a video. Nothing else. Free. Open source. Built for classrooms and stubborn hobbyists.

What it does

One window. Every feature is here to help you shoot a scene, not to admire itself.

Live view over USB

See exactly what the camera sees, in the app, at the camera's own frame rate. Every camera libgphoto2 supports.

Onion skinning that helps

Full-frame ghost or Sobel edge outlines of the previous frame. Adjustable opacity and count. Cyan tint so it doesn't fight the live view.

Two modes, no confusion

Add Frames for shooting, Preview for reviewing. Arrows / play / timeline in Preview; Space captures in Add Frames. That's it.

Scenes, ordered

Drag to reorder, rename inline, per-scene frame rate, deleted scenes go to trash, never destroyed. IDs like sc010 so inserting between two is sc015.

Never lose a frame

Every capture is a filesystem transaction. Files flushed to disk, journal appended atomically. Crash mid-session? Recovered on next launch.

Compile to MP4 or ProRes

H.264 for anywhere-playback, ProRes 422 for editing. Source resolution or 4K/1080p, crop or fit. Uses ffmpeg under the hood.

Dockable panels

Scenes, Viewer, Timeline, Camera, Onion Skin, Export — drag any tab header to rearrange. Set the app up the way your brain works.

Windows driver setup included

Bundles Zadig for the one-time WinUSB driver swap. In-app "Set up USB driver" button opens it with a click.

Three themes

Dark teal (default), dark amber, or light. Preferences → Theme. Swap on the fly.

Cameras that work

DragonSlayer uses libgphoto2's PTP driver, which covers hundreds of DSLR and mirrorless bodies made in the last 15 years. That includes most Canon EOS, Nikon, Sony Alpha, Panasonic Lumix, Fujifilm and OM System / Olympus cameras.

Reference camera: Panasonic Lumix GH5. Second test camera: Canon EOS 100D. Everything else should work — please open an issue with your make/model so we can add it to the compatibility list.

DragonSlayer is not a video editor

It captures frames and compiles them into a video. That's the whole job. To cut clips together, add music, add titles, grade colour or export for social — use a video editor. All of these are free.

Typical workflow: shoot in DragonSlayer → compile to MP4 → import into your editor → cut, colour, title, export.

Get started

Windows

  1. Grab the pre-built bundle from the Releases page and unzip it anywhere.
  2. Plug in your camera on USB, turn it on, set it to PC / PC(Tether) / PTP mode.
  3. Run DragonSlayer.cmd.
  4. If Windows is still using its own driver, click the "Set up USB driver…" button top-right — the bundled Zadig walks through a one-time WinUSB swap. Nothing on the camera changes.
  5. Click New project, Space to capture, H for the in-app help.

macOS

  1. Install Rust and libgphoto2. Full step-by-step in the macOS setup guide — assumes no prior experience.
  2. Quit Photos and Image Capture, then killall ptpcamerad.
  3. Plug in your camera in PC / PTP mode.
  4. Build and run: cargo run --release --features gphoto2 -p dragonslayer-app
  5. Click New project, Space to capture, H for the in-app help.

Where it lives

A DragonSlayer project is a plain folder. Copy it to a USB stick. Hand it in. Everything is text and JPEGs.

MyFilm/
  project.json                  # name, fps, scene order
  scenes/
    sc010/
      scene.json
      journal.ndjson            # capture history (frame order rebuilt from this)
      frames/
        000001.jpg
        000001.CR2
      incoming/                 # in-flight downloads; recovered after a crash
      trash/                    # deleted frames (never destroyed)
  trash/                        # deleted scenes
  exports/                      # compiled videos

What we won't build

A short list of things DragonSlayer deliberately doesn't do, because the whole point is to stay small.

  • ✕ No AI features — no auto-onion, no in-betweening, no generative anything. Every frame is a person's choice. Hard line.
  • ✕ No video editing / NLE — export to a real editor (see above).
  • ✕ No vector animation, tweening or drawing tools — that's Toon Boom / TVPaint territory.
  • ✕ No 3D rigging or puppeting — Blender / Cascadeur do that.
  • ✕ No paid tiers, subscriptions, telemetry or accounts. Ever.
